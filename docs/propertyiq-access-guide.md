# PropertyIQ Access Guide

Use this checklist after you purchase PropertyIQ on Payhip.

1. Open the PropertyIQ access link.
2. Enter the email used at Payhip checkout.
3. Enter the unique Payhip licence key from the receipt/download page.
4. Activate access.
5. Bookmark PropertyIQ.

Each licence is unique to your purchase. PropertyIQ does not use a shared bypass code. If you need to move to a new browser, sign out under Settings → PropertyIQ access, then activate again. Contact support if a legitimate device cannot activate.
